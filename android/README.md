# 淘金币助手 · Android 预览版

安装 APK 后直接在手机运行，**不需要电脑、ADB 或 Root**。适用于 Android 11 及以上。

这是将电脑版流程移植到安卓的首个预览版。已完成编译、任务规则测试及静态检查；当前尚未在真实手机上完成整轮验证，不能视为与电脑版兼容性相同。

## 手机怎么用

1. 将 `taobao-coins-0.1.0-preview.apk` 传到手机，点击安装，按系统提示允许本次安装来源。
2. 打开「淘金币助手」，点击「开启 / 管理无障碍权限」，在已安装的服务中开启本应用。
3. 如果出现「受限制的设置」，进入 **应用信息 → 右上角菜单 → 允许受限制的设置**，再开启无障碍。部分系统入口不同。
4. 确保淘宝已登录，手机处于竖屏、解锁状态。返回助手，点击 **开始淘金币任务 → 同意并开始**。
5. 暂时不要操作手机。右上角的 **停止** 按钮可以随时结束；也可返回助手点击停止。

运行结束后回到助手查看或复制日志。遇到验证或登录提示，手动处理后重新点击开始。

如果首次未找到任务面板，可先在淘宝手动打开「淘金币 → 赚更多金币」后再开始。若系统在运行中关闭了服务，可在应用电池设置中允许后台运行；关闭无障碍服务即可撤回操作权限。

## 已移植的流程

| 场景 | 行为 |
| --- | --- |
| 签到和到访奖励 | 进入金币页并领取可识别的奖励 |
| 浏览、逛清单 | 轻滑计时，识别完成提示后提前返回 |
| 搜索 | 选择页面当前显示的搜索建议 |
| 商品点击 | 只访问任务入口；缺少入口时跳过，不点击购买或加购 |
| 答题 | 按 A、B、C 尝试，有重答入口才继续 |
| 跨 App、游戏、付款、邀请、会员开通 | 过滤；意外离开淘宝则跳过本项并尝试返回 |
| 验证、登录、锁屏或无法截图 | 停止并显示原因 |

每项同一进度最多尝试两次。单轮最多执行 100 项、45 分钟；奖励以淘宝实际到账为准。识别规则会受当天页面和 OCR 结果影响，未适配的任务可能被跳过。

## 权限和数据

- 无障碍服务负责读取当前窗口、截图和执行手势；仅用户点击开始后运行，不随开机自动执行。
- 中文识别模型内置在 APK 中，本应用的最终清单不声明联网权限。
- 截图只放在内存中，识别后释放，不写入相册或文件。
- 最多保留本轮最近 300 条文字日志，运行结束后覆盖应用私有目录中的上一轮日志。清除应用数据或卸载即可删除。
- 运行中暂时保持屏幕亮起，结束时释放；仍需用户自行解锁。

## 从源码构建

需要 JDK 17、Android SDK 35 和网络连接下载构建依赖。设置 `JAVA_HOME`、`ANDROID_HOME` 后，在此目录运行：

Windows 建议将源码放在纯英文路径，例如 `C:\dev\taobao-coins`。部分 JDK / Gradle 组合在中文路径下编译成功，但测试进程可能无法加载测试类。

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleRelease
```

macOS / Linux 使用 `./gradlew`。输出位置：`app/build/outputs/apk/release/app-release.apk`。

预览版使用本机自动生成的调试签名密钥签署非调试 Release APK；密钥不入库。更新安装需要同一密钥，正式分发前应改用单独保管的发布密钥。不要把密钥或密码提交到 Git。

## 实现

`MainActivity` 提供授权说明、开始、停止和日志；`CoinService` 使用安卓无障碍截图、手势和内置 ML Kit 中文 OCR；`PageModel` 负责筛选和完成判定；`CoinEngine` 负责逐项执行与返回核对。

延续项目 Apache-2.0 许可证与来源说明。ML Kit 及其依赖按各自条款分发。
