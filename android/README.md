# 淘金币助手 · Android 预览版

安装 APK 后直接在手机运行，**不需要电脑、ADB 或 Root**。适用于 Android 11 及以上。

这是将电脑版流程移植到安卓的首个预览版。已完成编译、任务规则测试及静态检查；当前尚未在真实手机上完成整轮验证，不能视为与电脑版兼容性相同。

## 手机怎么用

1. 将 `taobao-coins-0.1.3-preview.apk` 传到手机，点击安装，按系统提示允许本次安装来源。已有版本可覆盖安装。
2. 打开「淘金币助手」，点击「开启 / 管理无障碍权限」，在已安装的服务中开启本应用。
3. 如果本应用是灰色或提示「受限制的设置」，先点击灰色的服务并关闭系统提示，再进入 **应用信息 → 右上角菜单 → 允许限制性设置**，按系统要求验证身份，然后再开启无障碍。三星上可能需要先触发一次拒绝提示，应用信息页才出现这个菜单；无需修改其他应用的权限。
4. 确保淘宝已登录，手机处于竖屏、解锁状态。返回助手，点击 **开始淘金币任务 → 同意并开始**。
5. 暂时不要操作手机。右上角的 **停止** 按钮可以随时结束；也可返回助手点击停止。

运行结束后回到助手查看或复制日志。**需要手动处理时会震动两下并暂停，不结束本轮**：完成验证、登录或手动打开「淘金币 → 赚更多金币」后，点击悬浮条的 **继续**，也可回到助手点击 **已处理，继续运行**。暂停期间不自动截图、点击或滑动；不需要拔插数据线或重开程序。震动是否可感知受手机硬件、静音与勿扰设置影响。

如果首次未找到任务面板，可先在淘宝手动打开「淘金币 → 赚更多金币」后再开始。若系统在运行中关闭了服务，可在应用电池设置中允许后台运行；关闭无障碍服务即可撤回操作权限。

`0.1.1-preview` 修复整排图标被当成“领淘金币”入口的问题，导航只采用独立标签及其实际边界，同一入口最多重试两次。无障碍未开启时，开始按钮会引导前往设置。

`0.1.2-preview` 增加手动处理时的震动提醒与暂停/继续。继续前重新检查页面，保留本轮已做任务与重试次数；需要人工干预的那次尝试不扣重试次数。程序仍会先自动寻找金币入口，找不到时才等待你操作。

`0.1.3-preview` 修复“更多金币等你赚”的展开：支持带箭头和“展开更多任务”等标签，滚动后仍可识别任务列表，返回后若再次折叠会重新展开。连续两次展开未变化时暂停请你检查。触屏打断手势、手势超时或辅助服务中断会暂停，点继续后重新读页面；点击停止仍会结束。已超时的排队操作会取消，避免暂停后又迟到执行。

## 已移植的流程

| 场景 | 行为 |
| --- | --- |
| 签到和到访奖励 | 进入金币页并领取可识别的奖励 |
| 浏览、逛清单 | 轻滑计时，识别完成提示后提前返回；自动展开更多任务并继续扫描 |
| 搜索 | 选择页面当前显示的搜索建议 |
| 商品点击 | 只访问任务入口；缺少入口时跳过，不点击购买或加购 |
| 答题 | 按 A、B、C 尝试，有重答入口才继续 |
| 跨 App、游戏、付款、邀请、会员开通 | 过滤；意外离开淘宝则跳过本项并尝试返回 |
| 验证、登录、锁屏、导航失败或无法截图 | 震动提醒并暂停，用户处理后点继续 |
| 触屏取消手势、手势超时、系统中断 | 保留本轮状态并暂停，点继续后重新核对页面 |

每项同一进度最多尝试两次。单轮最多执行 100 项、45 分钟，手动暂停时间不计入运行时长；奖励以淘宝实际到账为准。识别规则会受当天页面和 OCR 结果影响，未适配的任务可能被跳过。

## 权限和数据

- 无障碍服务负责读取当前窗口、截图和执行手势；仅用户点击开始后运行，不随开机自动执行。
- 中文识别模型内置在 APK 中，本应用的最终清单不声明联网权限。
- 截图只放在内存中，识别后释放，不写入相册或文件。
- 最多保留本轮最近 300 条文字日志，运行结束后覆盖应用私有目录中的上一轮日志。清除应用数据或卸载即可删除。
- 运行中暂时保持屏幕亮起，暂停和结束时释放；仍需用户自行解锁。暂停时只阻塞等待用户明确点击继续，不自动判断验证码是否已完成。
- 暂停状态和本轮任务进度保留在当前服务进程中。点击停止、关闭无障碍或系统回收进程后，需要重新开始；暂停时已保存的文字日志仍可查看。

## 从源码构建

需要 JDK 17、Android SDK 35 和网络连接下载构建依赖。设置 `JAVA_HOME`、`ANDROID_HOME` 后，在此目录运行：

Windows 建议将源码放在纯英文路径，例如 `C:\dev\taobao-coins`。部分 JDK / Gradle 组合在中文路径下编译成功，但测试进程可能无法加载测试类。

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleRelease
```

macOS / Linux 使用 `./gradlew`。输出位置：`app/build/outputs/apk/release/app-release.apk`。

预览版使用本机自动生成的调试签名密钥签署非调试 Release APK；密钥不入库。更新安装需要同一密钥，正式分发前应改用单独保管的发布密钥。不要把密钥或密码提交到 Git。

## 实现

`MainActivity` 提供授权说明、开始、继续、停止和日志；`CoinService` 使用安卓无障碍截图、手势和内置 ML Kit 中文 OCR；`ManualPause` 管理人工暂停与停止唤醒；`PageModel` 负责筛选和完成判定；`CoinEngine` 负责逐项执行与返回核对。

延续项目 Apache-2.0 许可证与来源说明。ML Kit 及其依赖按各自条款分发。
